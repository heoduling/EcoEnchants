# EcoEnchants 2026.27-3 同类装备预览修复与副作用审查

日期：2026-11-06，Asia/Tokyo。本次在用户审计确认后，按明确授权实施“同类普通装备跨材质共享本轮提示”。未部署生产服，没有重启或替换原生产同款测试服。以已交付2026.27-2为源码基线，不据此断言生产服已安装该版本。

## 最终行为

在玩家轮次、书架、权限与合法候选条件相同时，同类普通装备共享三档提示词条与等级。木、石、铜、铁、金、钻石、下界合金的剑算一类，镐另一类；斧、铲、锄、矛各自独立，盔甲按头/胸/腿/脚分开。乌龟壳头盔归入头盔并已实测。

弓、弩、三叉戟、重锤、书、盾等单一材质保留原材质键，不混进工具或盔甲组。未知组合保留原键，不根据targets集合中“第一个匹配项”决定分类。

分类只改变随机种子的稳定标识。原物品仍逐一执行原来的canEnchant资格检查，没有替换实际材质、删除名字/耐久/Lore/PDC、使用假想的统一物品，或放宽冲突、权限和专属限制。合法候选确实不同的特殊物品允许出现差异，不为强行统一提示加入不适用词条。玩家反馈中的自定义“刀”没有准确ID，本次没有把其他测试装备当作它。

沿用上一版已完成的零种子初始化、稳定候选排序、取消后原位重试、退出清理及核心成功付费后的轮次更新。旧性能优化保留。未增加费用、等待时间、数据库、定时器或新配置。

## 实现与审查

生产文件只改 `eco-core/core-plugin/src/main/kotlin/com/willfp/ecoenchants/mechanics/EnchantingTableSupport.kt`：onPrepare改用`enchantingPreviewType(item.type)`生成种子；新增有限的前缀/类别白名单和一个类型分类函数。另将gradle.properties版本更新为2026.27-3。

三遍检查功能、Folia/性能、生命周期，并由独立只读审查复核：未发现重要新增缺陷。

- 不改变原候选筛选、权重、等级计算、额外词条或收费代码。同一类在本次配置及测试权限下的七种普通材质候选池完全一致；最终逐物品与基线比较也完全一致。
- 新分类不遍历targets、不依赖集合顺序；类别键和原有候选排序跨JVM稳定。所有新增读取都在原Prepare事件上下文，没有新异步访问、调度、锁或跨区操作。
- 只新增固定大小的私有分类集合，每次查询处理短材质键；不新增按玩家、物品、改名或材质切换次数增长的缓存。现有prepared仍在下一次Prepare覆盖、退出时移除。
- 未测全服MSPT/CPU，不宣称绝对零开销或性能提升。没有全面重审整个插件，也未承诺所有第三方组合、热卸载或长期多人压力通过。

最终JAR与2026.27-2归档对比：有效业务指令改变仅EnchantingTableSupport，新增EnchantingTableSupportKt分类实现；ExtraItemSupport仅调试信息改变、反汇编指令相同。配置资源原样保留，仅plugin.yml版本改变，无依赖替换。

## 防筛选效果和玩家影响

在本次所测普通装备与合法条件下，每类原本七种材质可筛七套提示，现在只有一套。跨类别仍各有合法附魔池，成功付费仍可进入下一轮；脚本也仍能执行这些正常付费操作。本版不识别脚本、不限制点击频率，不承诺阻止全部自动刷附魔或给出整服脚本下降百分比。

这是本服选择的、比原版严格的防筛选规则，不是完整复刻原版材质附魔能力。上限、权重、效果与费用未改，但原有未完成的提示会在升级后按新类别键重新生成一次。之后同条件同类稳定。

额外可附魔SHIELD此前没有产生原生offers，其手动费用路径仍未覆盖；本次不修改该分支，也不扩大其通过声明。所有自定义物品的专属资格没有全量实测，最终仍依原物品资格过滤。

## 构建、安装与回滚

构建命令：

```text
gradlew.bat clean check shadowJar --offline --console=plain --max-workers=2 --init-script verification/preview/build-inputs.init.gradle
```

Gradle9.3.1、JDK25.0.3；基础目标Java21、26.2模块Java25沿用。init脚本固定此前使用的26.2.build.111-stable开发包，避免动态版本变化。源码含Wrapper、配置默认值、单测和隔离复测脚本；没有生产配置、数据库或世界存档。

正常停服，备份当前EcoEnchants，只保留一个加载副本，换入`EcoEnchants-2026.27-3.jar`后启动。无需改YAML、权限或数据库。回滚时停服换回原JAR；没有配置或存储迁移要回退。可以从之前交付的2026.27-1/2升级，本版累积保留之前修复。未自动部署、推送或更新GitHub PR。
